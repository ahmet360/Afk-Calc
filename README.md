# AFK Arena Dimensional Spirits Calculator (Companions)


A simple web-based calculator for **AFK Arena's Companions Server** event — *Dimensional Spirit Summons*.


This tool helps players estimate and plan their progress during the event, showing milestone rewards, expected spirit gains, and resource costs.


---


## 🧮 Features
- Calculates **expected Dimensional Spirits** (includes 2% RNG chance and milestone rewards)
- Displays all **20 milestone tiers** with rewards and estimated summon requirements
- Shows **cost breakdowns** in **Destiny Scrolls** or **Diamonds**
- Allows planning by total summons or target spirits
- Works fully offline — runs entirely client-side
